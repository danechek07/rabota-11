# Домашнее задание к лабораторной работе №11
(Вариант 19)

## Условие задачи
С одномерным массивом, состоящим из `n` вводимых с клавиатуры положительных и отрицательных целых чисел, выполнить следующие вычисления:  
**19. Среднее значение положительных элементов массива, расположенных по нечётным индексам.**  
(Использовать условный оператор `if` не рекомендуется)

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**  
2. Объявить переменные:  
   - `n` — размер массива,  
   - `arr[n]` — массив целых чисел,  
   - `sum` — сумма положительных элементов на нечётных индексах,  
   - `count` — количество таких элементов.  
3. Запросить у пользователя ввод `n`.  
4. Запросить ввод `n` элементов массива.  
5. Инициализировать `sum = 0`, `count = 0`.  
6. Пройти по массиву с индексами от `1` до `n-1` (нечётные индексы):  
   - Если элемент положительный — прибавить к `sum`, увеличить `count`.  
7. Вычислить среднее: `avg = sum / count` (если `count > 0`).  
8. Вывести результат.  
9. **Конец**
